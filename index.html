Cybersecurity · Networking

Network Intrusion Detection System

More code on GitHub

A rule-based NIDS written in Python. It uses Scapy to capture and read network traffic, either from a live network interface or from saved PCAP files, and raises an alert when traffic looks like an attack.

PythonScapyFlaskSQLiteChart.js
  1. TrafficLive interface or a PCAP file
  2. ScapyCaptures and reads each packet
  3. 5 enginesEach one looks for a different attack
  4. SQLiteEvery alert is logged
  5. DashboardLive Flask page with Chart.js charts
  • Two modes: watch live traffic, or replay a PCAP file offline.
  • A live dashboard with charts for real-time threat monitoring.
  • An alert log stored in SQLite.
EngineLayerWhat it catches
Port ScanL4One host probing many ports to find which services are open.
SYN FloodL4A burst of TCP connection requests meant to use up a server's resources.
ICMP FloodL3A burst of ping packets sent to overload a target.
ARP SpoofingL2Fake ARP replies used to sit between two devices on a local network.
DNS TunnelingL7Data hidden inside DNS queries to slip past network filters.
  • Sliding time-window rate analysis. Counts packets inside a moving window of time and flags sudden bursts.
  • Shannon entropy scoring. Measures how random a piece of data looks. Hidden or encoded data looks very random, which can give tunneling away.

A small demo of how alerts can look. The traffic is made up and this is not output from the real tool. Pick an attack and watch the packet rate.

Secure Password Manager

View on GitHub

A full-stack password manager built with security first. It has a web app and a light CLI version that works offline, so passwords can be managed with or without a browser.

PythonFastAPIReactCryptography
  1. React appThe screen where you use the vault
  2. FastAPI REST APIHandles sign-in and saved credentials
  3. Argon2id + FernetProtect the master password and the saved logins
  • Master password. Hashed with Argon2id, a slow hash that is built to make password guessing expensive.
  • Saved logins. Encrypted with Fernet. It is authenticated encryption, so data cannot be read or quietly changed without the key.
  • REST APIs. Secure endpoints for authentication and credential management, written with secure coding practices.
  • Auto-lock. Shuts the vault so it is not left open on screen.

VLAN, DHCP and DNS Network Lab

View on GitHub

A small office network with separate VLANs, a router connecting them, automatic IPs and a DNS server.

Cisco Packet TracerCisco IOS CLI

I built a small office network in Cisco Packet Tracer. It has 3 VLANs (Staff, IT and Server) on one switch. A router connects them using router on a stick over a trunk link. The router also gives IP addresses by DHCP, and a server runs DNS and a web page, so PCs can open www.college.local by name.

I tested it with ping, ipconfig and show commands. Along the way I fixed real problems: a shut down router port and a missing DNS record.

  • 3 VLANs with trunk and inter-VLAN routing
  • DHCP with excluded address range and DNS option
  • DNS and web server working by name
  • Tested and troubleshot step by step
